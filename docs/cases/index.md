# 案例库

案例库只收录能复现、能迁移、能验收的真实任务。

每个案例都应该写清楚：

- 背景是什么。
- 输入材料是什么。
- 给 Codex 的任务怎么写。
- Codex 做了哪些动作。
- 怎么验证结果。
- 哪些地方失败过。
- 这个案例适合迁移到什么场景。

## 案例模板

```md
# 案例标题

## 背景

这个任务为什么要做。

## 输入

给 Codex 的材料、文件、链接或截图。

## 任务提示词

实际可复用的 prompt。

## 执行过程

Codex 读了什么、改了什么、跑了什么验证。

## 验收

成功标准和验证命令。

## 复盘

哪里做得好，哪里容易踩坑。
```

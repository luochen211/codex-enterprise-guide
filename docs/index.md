## 你停在哪一层

![四个层次](/book/ch00-1.webp)

| 层次 | 标准 |
| --- | --- |
| Demo | 自己电脑上能演示 |
| 完整 | 功能齐全、能上线 |
| 生产级 | 上线后一直稳定跑：出事能发现、能恢复，改版时不停机 |
| 商业级 | 有人付钱用：钱算得清，数据和法规守得住，成本算得过来，出错有人追责 |

大多数教程停在 Demo，好的面试题答卷能到「完整」。这本书要带你走到后两层。

## 每章只讲两件事

| 交给 AI 的 | 你要判断和验收的 |
| --- | --- |
| 设计数据、写代码、写测试、配部署、接支付 | 业务对不对、范围怎么取舍、做没做完、线上真的能用、钱算得清、出事有证据 |

## 一个贯穿全书的示例项目

示例项目是一个餐厅运营后台，来自作者做过的一道全栈面试题：1–2 天内做出菜单、订单、顾客、设置和经营首页。前两部分拿它当「完整」的样板，后三部分讲怎么把一道面试题做成能收钱的系统：补上登录与角色、在线支付、监控、合规、成本和交付。

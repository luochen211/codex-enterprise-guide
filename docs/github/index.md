# GitHub 入门小课

六节课，学完你能做到这几件事：

- 把自己的项目放到 GitHub 上，改坏了能退回去；
- 用分支和 PR 改代码，不直接动主线；
- 用 Issue 记下每一件要做的事；
- 让 GitHub Actions 在每次推送后自动检查、自动上线；
- 不把密钥和客户数据传上去；
- AI 替你提交和开 PR 时，知道该检查什么。

不需要先学会 Git 的原理。只要会打开终端、照着输入命令就行。命令也可以交给 AI 去敲，但每一课最后的「你要判断和验收的」得你自己来。

## 课程列表

| 课 | 学完能做什么 |
|---|---|
| [1 · 仓库和提交](/github/repo-and-commit) | 把项目放上 GitHub，每做完一步存一个档，改坏了能退回去 |
| [2 · 分支和 PR](/github/branch-and-pr) | 改动先在分支上做，经过 PR 检查再合进主线 |
| [3 · Issue](/github/issue) | 一件事开一个 Issue，PR 合并时自动关掉它 |
| [4 · Actions](/github/actions) | 推送后自动构建、测试、上线，红了知道怎么查 |
| [5 · 什么不能进仓库](/github/secrets) | 密钥放进 Secrets，`.gitignore` 挡住不该传的文件，泄露了怎么补救 |
| [6 · 让 AI 操作 GitHub](/github/ai) | 给 AI 定规矩，验收它交来的 PR |

按顺序读，每课十来分钟。每课最后有一个小练习，建议拿一个自己的小项目跟着做一遍。
